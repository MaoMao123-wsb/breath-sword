左侧出剑：短按松开近斩；按住 0.45 秒以上再松开发剑气，1.5 秒蓄满。按住拖动能走位。

危的亮环出现时应对，成功送满蓄攻击并回气。贴脸满蓄斩伤害 ×1.5。
